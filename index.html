API Information

Base URL

https://dear-nobody-api-production.up.railway.app

Authentication

Protected endpoints require a JWT token. 

Authorization: Bearer [TOKEN return from POST/login]

1. Sign Up

POST /signup

Request

{
  "username": "Alice",
  "email": "alice@example.com",
  "password": "123456"
}

Expected Result

Creates a new user and stores the password securely as a hashed password.

Example Response

{
  "message": "User created successfully",
  "user": {
    "id": 1,
    "username": "Alice",
    "email": "alice@example.com",
    "created_at": "2026-10-05T10:00:00.000Z"
  }
}

Error Example

{
  "error": "Username or email already exists"
}

Status: 400 Bad Request

2. Log In

POST /login

Request

{
  "email": "alice@example.com",
  "password": "123456"
}

Expected Result

Verifies the user's email and password and returns a JWT authentication token.

Example Response

{
  "message": "Login successful",
  "token": "YOUR_JWT_TOKEN"
}

Error Example

{
  "error": "Invalid email or password"
}

Status: 401 Unauthorized

3. Get Users

GET /users

Request

No request body is required.

Authentication header: 

Authorization: Bearer YOUR_TOKEN

Expected Result

Returns a list of registered users.

Example Response

[
  {
    "id": 1,
    "username": "Alice",
    "email": "alice@example.com",
    "created_at": "2026-10-05T10:00:00.000Z"
  },
  {
    "id": 2,
    "username": "Bob",
    "email": "bob@example.com",
    "created_at": "2026-10-05T10:05:00.000Z"
  }
]

Error Example

{
  "error": "Authentication token is required"
}

Status: 401 Unauthorized

4. Add Friend

POST /friends

Request

Authentication header: 

Authorization: Bearer YOUR_TOKEN

Request body:

{
  "friend_id": 2
}

Expected Result

Creates a friendship between the authenticated user and the selected user.

Example Response

{
  "message": "Friend added successfully",
  "friendship": {
    "id": 1,
    "user_id": 1,
    "friend_id": 2,
    "created_at": "2026-10-05T10:10:00.000Z"
  }
}

Error Example

{
  "error": "Friend not found"
}

Status: 404 Not Found

Another possible error:

{
  "error": "You cannot add yourself as a friend"
}

Status: 400 Bad Request

5. Create Post

POST /posts

Request

Authentication header: 

Authorization: Bearer YOUR_TOKEN

Request body:

{
  "content": "Hello from Dear Nobody!",
  "visibility": "Public"
}

Visibility options:

  • Public
  • Friends-only

Expected Result

Creates a new post for the authenticated user.

Example Response

{
  "message": "Post created successfully",
  "post": {
    "id": 1,
    "user_id": 1,
    "content": "Hello from Dear Nobody!",
    "visibility": "Public",
    "created_at": "2026-10-05T10:15:00.000Z"
  }
}

Error Example

{
  "error": "Content and visibility are required"
}

Status: 400 Bad Request

Another possible error:

{
  "error": "Visibility must be Public or Friends-only"
}

Status: 400 Bad Request

6. Get Posts

GET /posts

Request

No request body is required.

Authentication header: 

Authorization: Bearer YOUR_TOKEN

Expected Result

Returns:

  • Public posts from all users
  • Your own posts
  • Friends-only posts from your friends

Example Response

[
  {
    "id": 2,
    "user_id": 2,
    "content": "Hello everyone!",
    "visibility": "Public",
    "created_at": "2026-10-05T10:20:00.000Z",
    "username": "Bob"
  },
  {
    "id": 1,
    "user_id": 1,
    "content": "This is my private friends post.",
    "visibility": "Friends-only",
    "created_at": "2026-10-05T10:15:00.000Z",
    "username": "Alice"
  }
]

Error Example

{
  "error": "Authentication token is required"
}

Status: 401 Unauthorized

Post Visibility

Public

A Public post can be seen by all authenticated users.

Friends-only

A Friends-only post can only be seen by the post owner and users who are friends with the post owner.
